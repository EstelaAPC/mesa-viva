# Mesa Viva

Uma experiencia Angular para descobrir receitas, salvar favoritos e montar uma semana gostosa sem complicacao.

## Funcionalidades

- Busca por nome de receita
- Filtros por categoria
- Favoritos com estado interativo
- Planejamento semanal de pratos
- Layout responsivo para desktop e mobile

## Executar

```bash
npm install
npm start
```

Acesse `http://localhost:4200/`.

Para criar o build de producao:

```bash
npm run build
```

## Publicar no GitHub

Crie um repositorio vazio chamado `mesa-viva` e execute:

```bash
git add .
git commit -m "feat: create Mesa Viva recipe planner"
git branch -M main
git remote add origin https://github.com/EstelaAPC/mesa-viva.git
git push -u origin main
```
